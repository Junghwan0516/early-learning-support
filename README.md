# early-learning-support

Predicting later course withdrawal from the first 28 days of online learning activity.

This project investigates a practical question: if an educator can review only 10% of learners, which approach identifies the most learners who later withdraw?

Using the public Open University Learning Analytics Dataset (OULAD), the project will compare a low-activity baseline, logistic regression, and random forest using chronological training, validation, and test splits.

**Current status:** Data preparation and boundary-condition checks are complete. Model training, performance evaluation, and deployment are pending.

This is an independent educational machine learning portfolio project. It uses historical UK university data; its performance on current learners or other institutions has not been established.
